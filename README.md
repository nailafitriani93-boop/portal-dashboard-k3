# Portal Dashboard K3

Portal dashboard bergaya sama dengan referensi yang diberikan, dengan menu:

1. Inspeksi K3
2. Rekap Data Kecelakaan
3. Stock APD
4. Distribusi APD
5. Jadwal Order APD

## Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

Tombol card sudah dibuat sebagai navigasi placeholder ke:
- `/inspeksi-k3`
- `/rekap-kecelakaan`
- `/stock-apd`
- `/distribusi-apd`
- `/jadwal-order-apd`

Halaman tujuan belum dibuat karena fokus paket ini adalah portal dashboard.
